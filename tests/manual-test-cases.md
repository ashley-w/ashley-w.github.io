# Manual Testing Checklist for TropeOut

## Core Functionality
- [ ] User can start a new game
- [ ] User can view daily puzzle
- [ ] User can submit an answer
- [ ] User receives feedback on the answer (correct/incorrect)
- [ ] User can view score after submission

## Local Storage
- [ ] User data is saved after game completion
- [ ] User data is retrieved correctly on game restart
- [ ] User can reset their progress

## UI/UX
- [ ] Game interface is responsive on mobile devices
- [ ] All buttons are functional
- [ ] Game rules are accessible from the main menu

## Edge Cases
- [ ] User cannot submit empty answers
- [ ] User receives appropriate error messages for invalid inputs
- [ ] Game handles unexpected errors gracefully

## Additional Features
- [ ] User can share results via text
- [ ] Daily trope changes at midnight
- [ ] Game tracks user statistics over time

## Notes
- Ensure to test on multiple devices and browsers for compatibility.
- Document any bugs or issues encountered during testing.
